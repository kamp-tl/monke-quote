monke Quote is a typing game I built to work on increasing my typing pace. With this project, I was looking to practice asynchronous JavaScript as well as validating data input. The name is a tongue-in-cheek reference to Monkeytype, a popular typing website.

The game is initiated by pressing Space, and immediately, a quote will be generated. The objective is to type the quote exactly as you see. Once the typed text matches the quote exactly, the quote is sent to the wallpaper and replaced by another. Once five quotes have been typed, the input field disappears to reveal the wall of quotes you just typed.

This application is currently deployed to [kamp-tl.github.io/monkeQuote](https://www.kamp-tl.github.io/monkeQuote)
